SQL Estate Analyzer

Azure target sizing & cost modelling for SQL Server estates
🔒 No data leaves your browser · 100% client-side

Drop your SQL estate inventory here

CSV or Excel produced by the discovery script — or any inventory with matching columns

1

Run the discovery script

Execute SqlEstateDiscovery.sql against each SQL Server instance. It is read-only and collects no schema, data or query text — only versions, sizes and feature flags.

2

Export to CSV

In SSMS, right-click the results grid → Save Results As… → CSV. Repeat per instance; you can upload all the files together.

3

Review the options

Get a recommended Azure target per database, the blockers behind every rejected option, and costs across PAYG, reserved and Hybrid Benefit scenarios.

Not from the discovery script? Any CSV/Excel works as long as it has one row per database. The analyzer auto-detects common column names and you can remap anything it misses. The essentials are: server/instance name, database name, SQL version, edition, core count and database size.
